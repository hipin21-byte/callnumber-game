청구기호 서가 정렬 연습

가상 도서 50권을 실제 서가처럼 배열하고, 채점·오답 이유·정답 위치를 즉시 확인합니다. 정답 순번을 유추할 수 있는 책 번호는 표시하지 않습니다. 채점 결과는 관리자용 점수판에 전송할 수 있습니다.

대학도서관 근로학생 교육용 · v2.5

배열 핵심 규칙

  1. 첫째 줄부터 비교
  2. 같으면 왼쪽부터 비교
  3. 영어 표기가 한글 표기보다 먼저
  4. 앞부분이 같으면 짧은 표기가 먼저
  5. 분류기호는 작은 번호에서 큰 번호로
📘 청구기호 이론학습 PDF 교육자료 기준
1. 청구기호의 구성
청구기호는 책의 서가 위치를 나타내며, 교육자료에서는 다음 요소로 구성됩니다.
별치기호 분류기호(KDC) 도서기호(저자기호) 부차적기호
예: R / 912.03 / ㅅ137ㅅKㄱ / v.1 c.2
권호(v.), 복본(c.), 판차 등은 부차적기호로 봅니다.
2. 청구기호 배열의 대원칙
① 첫째 줄부터 본다.
② 왼쪽부터 본다.
③ 영어 표기가 한글 표기보다 먼저 온다.
④ 앞부분이 같으면 글자 수가 적은 것이 먼저 온다.
3. 기본 배열 예시
같은 분류기호·저자기호 아래에서 다음 글자를 비교합니다.
ㅈ → ㅈ2 → 자 → 장 → 자ㅎ → 자흐 → 자흥 → 장ㅎ → 장흐 → 장흥
한 글자 → 숫자가 붙은 표기 → 두 글자 계열 순으로 왼쪽부터 비교합니다.
4. 심화 배열: 번역서·권호·복본
교육자료의 심화 예시는 다음 순서를 사용합니다.
Kㄱ → Kㄴ → Kㄷ → v.1 → c.2 → c.3 → 상 → 上
K: 번역서
v.: 연속간행물/권호
c.: 복본
교육자료에는 “최신자료는 한자 사용 안 함”이라고 제시되어 있습니다.
5. 번역서 배열 예시
교육자료의 예시는 다음과 같습니다.
d → d Kㄱ → de Kㄱ → del Kㄱ → dk → dl Kㄱ
앞부분이 같은 계열은 그 계열을 먼저 끝낸 뒤 다음 글자로 넘어갑니다. 교육자료에는 “de류가 다 끝나야 df가 옴”이라고 설명되어 있습니다.

7. 국내서·동양서 도서기호 적용 규칙
이 게임에서는 국내서·동양서의 도서기호를 다음 방식으로 연습합니다.
저자 성의 첫 자음 + 저자명 숫자 + 서명 첫 글자의 초성
예: 토지 / 박경리 → ㅂ172ㅌ
따라서 가상 도서에서도 서명 첫 글자의 초성과 도서기호 끝 초성이 일치하도록 구성합니다.
국내서·동양서 도서기호 규칙
저자 성의 첫 자음 + 저자명에 해당하는 숫자 + 서명 첫 글자의 초성
예) 토지 / 박경리 → ㅂ172ㅌ
※ 따라서 가상 도서도 서명 첫 글자의 초성과 도서기호 끝 초성이 반드시 일치하도록 구성했습니다.

① 책을 드래그해 원하는 위치로 이동하거나
② 책 2권을 차례로 클릭해 서로 교환합니다.
③ 화면 맨 위·아래로 책을 끌면 페이지가 자동 스크롤됩니다.
